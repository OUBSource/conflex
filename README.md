# Conflex

Smart configuration loader for Python with validation, inheritance and secrets support.

## Features

- 🔄 **Auto-format detection** (YAML, JSON)
- 🏗️ **Configuration inheritance** (multiple files)
- ✅ **Schema validation** with Pydantic
- 🌳 **Dot notation access** to nested values
- 🔐 **Environment variables** support with prefix
- 🚀 **Type hints** throughout

## Installation

```bash
pip install conflex
